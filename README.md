# CALIBROˢ institutional website

Static, responsive website for the CALIBROˢ product.

## Local preview

Open `index.html` in a browser, or serve this directory with any static HTTP server.

## Structure

- `index.html` — page content and semantic structure
- `styles.css` — responsive visual system
- `script.js` — small navigation and footer enhancements
- `favicon.svg` — site icon

The site is intentionally framework-free and has no build step. GitHub Pages deployment will be configured separately once the content and publishing setup are agreed.
